#  Sistema de Gestión de Instituto

Proyecto en Java que permite gestionar un instituto con alumnos, profesores, aulas, incidencias y reservas usando Hibernate (JPA) y MySQL.

---

## 🚀 Tecnologías usadas

- Java 17+
- Swing (interfaz gráfica)
- Hibernate (JPA)
- MySQL
- Maven

---

## 📂 Estructura del proyecto

- `model` → Entidades (Alumno, Profesor, Aula, Incidencia, Reserva)
- `dao` → Acceso a datos (CRUD con Hibernate)
- `view` → Interfaces gráficas (Swing)
- `util` → Configuración de JPA

---

## 🗄️ Base de datos

Nombre de la base de datos: Instituto
